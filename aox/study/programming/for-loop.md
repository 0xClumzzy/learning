*Philosophy*
	repeat the code for a number of times
	`for(initialization;condition;update)`
```
for(<returntype> variable=somevalue; condition; update)
```
eg 
```
for(int i = 0; i < 10; i++){printf("yes");}
```
*start at zero, if i is less than 10 increment i by itself*
eg
```
for(int i = 2; i < 10; i+=2){printf("yes");}
```
*start at 2.....increment i by 2*
